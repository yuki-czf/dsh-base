1. **每棒收敛自检**：TaskWait 回来→追加 facts 前必跑 `git status --porcelain` 对比授权集；授权集外有改动或棒报告与工作树不符 → **停止而非重派**（写 handoff）。原理：把「别写源码」的禁令（三连失守）换成「每棒跑一条检查命令」的程序步骤（274 实测此类检查步骤执行率 100%，跑过 8 次 git status）＋把违规反应从「重派继续」改为「停」。
2. **等待窗口纪律**：等待期间只做 2.5 四类合法动作，**禁 Read 源码本体**（433 次 Read 是 ctx 烧穿主因——调度器读报告/facts/接力表即可，不需要读 862 行组件）。
3. **返工棒单一 owner**：复审发现问题 → 一支返工棒（gemini-fixer，简报=问题逐条清单＋复现验证命令）吃完所有发现；返工期间同接力纪律，主会话禁参与返工；返工棒重派 ≥2 熔断。
4. **可选只读模式**：本端若有会话级只读模式且不阻 Task 派发 → 开工即切（物理剥夺 Edit/Write）。**未强制原因**：PI-Desktop plan mode 是否放行 Task 派发无法在宿主外验证，不能把接力押在未验证的宿主行为上。
