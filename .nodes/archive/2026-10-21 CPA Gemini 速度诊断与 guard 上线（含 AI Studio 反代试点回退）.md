# 2026-10-21 CPA Gemini 速度诊断与 slow-guard 上线（含 AI Studio 反代试点回退）

> 来源：coze_app 工作区会话 main（2026-10-20 ~ 10-21）。本报告为云端自包含**脱敏版**：不含服务器 IP、账号邮箱明文、密钥、具体域名端口。完整细节（配置路径、回退备份位置、密钥文件）仅存源工作区本地 .nodes/（节点 #49 slow-guard、#51 aistudio-pilot）。

## 1. 背景

- **降速波**：10-20 晨 CPA Gemini（Google AI Pro 订阅 ×2，Antigravity 协议接入）真实流量恶化——中位首字 14.9s / p90 59.7s / 解码均速 65 t/s，定性为上游 -n 慢池挤压（美区晚高峰主导），BJ 白天持续
- **链路拓扑**（角色化）：Agent 客户端（公司/家）→ 跨洋加密隧道/TLS → 美国 VPS（洛杉矶：Caddy → slow-guard → CPA 网关，三层 localhost 接力）→ Google 上游
- **两天主线**：10-20 尝试 AI Studio 反代逃生通道（失败回退）→ 10-21 诊断真实瓶颈 → slow-guard 由 observe 切 guard 模式上线

## 2. AI Studio 反代试点（10-20，已回退）

**架构**：AIStudio2API v0.2.13（纯 Go WAA 后端，无浏览器，~211MB）部署于中转节点 + 美国 VPS SOCKS 出口（IP 配对铁律：登录/运行出口统一）+ 反代双入口 + LE 证书。账号经 Chrome 批量导入（en-US / 洛杉矶时区指纹）。

**实测性能（成功面）**：

| 场景 | 首字 | 速度 |
|---|---|---|
| 节点本地直连 | 2.3-4.2s | 146-198 t/s |
| 家宽公网真实路径 | 5.55s | ~130 t/s |
| 8.5K token 大输入 | 3.07s | 正常 |
| 同期 Antigravity 慢池对照 | 14.9s（中位） | 65 t/s |

缓存命中 74-92%，WAA proof 仅 ~200ms——**速度层面完胜慢池 3 倍**，慢链路（中转节点入向带宽极低）也证明不是瓶颈（SSE 仅 KB 级）。

**致死缺陷（源码级证实，回退根因）**：

1. **Chrome 导入凭据是一次性的**：续签路径依赖 Windows DPAPI，Linux 上报「Chrome OAuth 导入仅支持 Windows」；导入 cookie 约 2 小时后 401 死亡
2. **v0.2.13 登录浏览器不认代理**：--proxy / .env PROXY 参数均传入但浏览器实际零代理流量（出口端日志实证），直连即死于 DNS 污染（UNKNOWN_HOST）；公司/家两地 6+ 次浏览器登录全败于此

两条路互相堵死：导入型不可续签、原生型登不进 → 试点不可持续，**用户拍板全量回退**。

**回退执行**：出口代理服务、防火墙规则、~2.5G 传输文件、应用服务、密钥、站点、证书、本机 ~700M 副本全清。**保留**：CPAMP 面板两处升级回归修复（307 跳转改写 + 6.4MB 静态镜像直出，首载 5-21s → 1.3s）。

**复活条件**：上游修复登录浏览器代理失效 bug，或导入凭据的 Linux 续签支持；届时必须浏览器原生登录，配方可原样复用（已入档）。

**附带事故教训**：①替换系统命令必须原子操作（curl 包装器自指递归 ≈ fork bomb，负载飙至 14.6）；②反代层间歇 RST 截断大响应（静态资源磁盘直出绕过）。

## 3. CPA 速度诊断（10-21）

### 3.1 探针初测（表面健康）

小请求（16 token）首字 3.5-4.2s；8K token 输入 4.8s；非流式精确解码 **~200-220 t/s**（493 tok / 6.45s 与 1693 tok / 11.74s 双验证）——中位数回到物理区间。

### 3.2 真实流量对质（slow-guard 观测账本，116 笔，工作时段 75 分钟）

| 请求体量 | n | p50 首字 | p90 首字 | 最差 |
|---|---|---|---|---|
| 小 <150KB（~35K tok） | 24 | 5.1s | 7.8s | 11.1s |
| 中 150-250KB | 43 | 5.3s | **16.2s** | **50.7s** |
| 大 >250KB（~60-80K tok） | 49 | 6.2s | **22.2s** | **75.1s** |

- **84% 的请求是 100-350KB 大包**（Agent 工具循环累积：读文件/终端输出全部留在历史里逐步重发；实测同一工作段内请求体 125KB → 323KB 持续膨胀）
- 全体：p50 5.8s / p90 16.4s / max 75.7s

### 3.3 三连发实验（彩票实锤）

同一 293KB 载荷、同一路径连续三发：**7.5s → 66s → 32s**。路径不可能 10 倍波动 → 上游随机排队实锤；同路径 16 token 小请求仅 3.5s 作对照。

### 3.4 路径洗白（回应「是不是 VPS/中间层慢」）

- 跨洋路径税合计 **每步 ~1-2.5s**（TCP+TLS 握手 0.4-0.6s + 300KB 跨洋上传 ~1s）——主要是物理成本
- VPS 内 Caddy → slow-guard → CPA 三层 localhost 接力，实测无可测差异（毫秒级）
- **结论**：中位 6s 里 ~5s 在上游 prefill（随上下文线性），尾部 16-75s 100% 是上游排队；路径优化收益上限 1-2s，不值得动

### 3.5 体感慢公式

每步 ~6s prefill 地板（上下文越大越贵） + 12-15% 概率抽中 15-75s 死签（20 步任务撞 2-4 次） + 1-2.5s 路径税

## 4. slow-guard 切换（observe → guard，10-21 生效）

**规则**（设计于 10-19，当日部署 observe 先行）：

| 规则 | 内容 |
|---|---|
| 15s 首字阈值 | 首字节超 15s → 取消上游、重发 1 次（重新抽签） |
| 只重发 1 次 | 重发仍慢则让它跑完（90s 绝对死线封顶） |
| 连续 2 笔触发 | 退避 5 分钟（整池堵塞时避免白烧） |
| 已吐字节永不重试 | 保证客户端流连贯，绝不重复/错乱 |

**校准依据**（observe 116 笔）：中位 5-6s 距 15s 阈值遥远 → 误杀率≈0；尾部 16-75s 正是目标。15s 阈值当初即为避开正常思考期设定（思考中会先吐 reasoning 流）。

**切换与验证**：unit 文件 -mode observe → -mode guard，等流量空隙重启；启动日志确认 mode:guard；三发探针（小请求 + 300KB×2）全部正常放行。原配置备份 bak-observe，一句话可回退。

**效果预期**：30-75s 死签 → 典型 ~20s 封顶（15s 砍 + 重签快签）；正常请求零干扰（中位数完全不动）；对客户端完全透明。日志出现 action:retry 即救场记录，可定期统计拯救次数与节省秒数。

## 5. 遗留与建议

1. **上下文瘦身（主要抓手）**：读文件用局部读（先搜索定位再读段落）、不反复读同文件、一任务一会话、长会话中期压缩历史——包小则 prefill 地板与抽签率同时下降（小包桶 p90 仅 7.8s）
2. **guard 效果观察**：跑 1-2 天后统计 retry 记录，评估是否收紧阈值
3. **旧挂账**：模型哨兵（404→200 翻转监控）、Keeper v2 升级、家侧 WG 隧道当前未起
4. **上游观察**：-n 慢池恢复与否只能靠持续采样判断；本轮证明「中位健康 + 尾部彩票」是新常态
