## 调度器动作清单（照单，无判断环节）

1. 读档（CONTEXT/PROGRESS/本计划一批并发）→ 一行状态 → 查执行槽（本节点=执行:执行接力）→ 进接力分支
2. 批0：派 scout（六段简报：GOAL=取基线原文 / 验收=逐行原文 / 文件集=只读无 / 已验证事实=工作区 G:\www\dsh-base、git 可用 / 验证=回报行数与内容自洽 / 终止=1 次往返）→ 回报落 baseline.txt（调度器写 `.nodes/` 合法）
3. 批1a+1b **同消息并发派两支 fixer**（各自六段简报照上表范围+验收+事实；事实要点：discrepancies.md 现有 15 条、标题格式「N. **标题**」；README.md 不存在需新建）
4. 每棒收敛：报告事实追加 facts.md（各段 ≤300 字）→ 等双到齐
5. 批2：派 scout 越界复核 → 对比基线 → 判定写 facts.md
6. 批3：派 review（简报=上表验收列+两文件路径+diff 摘要；**换 provider**）→ 回报不完整即重派（≥2 熔断）
7. 收口：`save.ps1 checkpoint -Node 试跑草稿目录文档化 -Note <结论>`（调度器无 pwsh 时把 checkpoint 动作写进最终回复，由用户转告 main 会话执行）
