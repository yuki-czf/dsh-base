# plans/ 分批执行约定

> 目的：上下文窗口受限（131K），大节点按体量拆批，**一批 = 一个新会话**，从机制上避免压缩。
> 状态：约定级试点。#4 验收通过后评估固化进协议（v1.3.0 候选）。
> 创建：2026-08-27

## 立节点先问（询问制，二选一不混用）

登记节点时若工作超出单会话预算，**先问用户走哪条约定，再落计划**：

1. **spec-superflow**：proposal/specs/design/tasks + execution-contract 门禁（重型，适合要评审、跨变更交付的正式工作）；
2. **本目录分批约定**：plans/<节点名>.md 六列表 + 一批一会话 + 批末 verify-batch/commit 收口（轻量，适合连续推进、逐批验收的工程活）。

两者**不得混用**（不许 spec-superflow 的 tasks.md 当批次计划，也不许用批次表替代 execution-contract 门禁）。用户不表态 → 默认走本目录轻量约定并在会话中说明。

## 使用方式

登记节点时预判超预算（且已按上节询问制选定本约定）→ 在本目录建 `<节点名>.md` 批次计划 → 每个新会话说
「读档，执行 `<节点>` 第 N 批」→ 批末走标准五步存档。

opencode 加速通道：全局 agent `batch-executor`（`~/.config/opencode/agents/`）已固化
上述纪律——新会话选它，说「执行下一批」（自动取第一个未完成批）或「执行第N批」，
批末自动存档并停。注意两点：立节点拆批仍用大模型 build 会话（内置 plan agent 只读，
不能落盘存档）；agent 的 `model` 字段硬编码公司 vLLM 模型 ID，换模型需同步修改。

链式模式（2026-08-27 起）：batch-executor 批末 verify 全过后**自动派生下一批新会话**
（openchamber session.create；先存档后派生，崩溃必停在干净边界；单会话单派生；
无 openchamber 工具的环境不派生、给出手动恢复话术）。失败/设计分叉/待验收 →
立即断链等人；恢复只需新会话说「执行下一批」。总验收永远由人或大模型会话收口。

## 试点经验回灌（2026-08-27 ~ 08-28，节点5 v1.3.0 试点）

1. **验收以磁盘为准**：v130-b2/b3 均出现「提前声明完成」，后续批次一律以 `verify-batch` 实跑输出为唯一收口凭据，不采信会话内口头声明。
2. **verify-batch 的 `-Node` 必须与 PROGRESS 节点名逐字一致（含空格）**，否则节点行匹配失败、校验项 FAIL。
3. **PS 5.1 对 .ps1 编码敏感**：LF 行尾（无 BOM）会导致 GBK 解码中文注释产生奇数 0x27 字节、破坏字符串解析；花括号不匹配时 verify 会静默失效。母版 .ps1 一律 BOM+CRLF，中文注释转英文。
4. **收口中断由 main 补全**：批2/3 的收口（存档/verify）在派生下一批前中断，均由 main 会话补全后重派——批末存档必须在派生动作**之前**完成，保证崩溃停在干净边界。
5. 阈值校准：批1 ≈13K、批3 ≈22K（多文件读改）均无压缩，30K 阈值维持（详见各批次计划文件校准日志）。

## 六条纪律

1. **拆批时机**：登记节点时预判会超预算 → 同时落批次计划文件；PROGRESS 状态列记 `进行中·批N/M`。
2. **切割原则**：按复杂度切，不按文件大小切——思考密集的步骤单独成批；批间靠文件/接口衔接，不靠记忆。
3. **一批一会话**：新会话开工照常读档（CONTEXT + PROGRESS + 本批次计划），只读本批相关档案，不全量回灌；**会话标识按批轮换**（如 `<节点>-b<N>`），避免 SESSIONS 整文件重写覆盖上一批暂停点。
4. **批末必存档**：走标准五步存档；SESSIONS 暂停点写「本批完成 X / 下批起点 Y」，CONTEXT 下一步指向第 N+1 批。
5. **超限即断**：察觉接近压缩点或实读材料超阈值 → 提前收口存档换下一会话，不硬撑。
6. **校准回路**：把实际压缩点/耗时记回本计划文件的校准日志，回头调阈值（默认 30K 起步）。

## 估算口径备查

- 中文 ≈1 token/字；代码 ≈10–15 token/行；固定底噪（系统提示+skills+AGENTS）≈10–20K；读档案 ≈2–8K
- 阈值约束的是**读进上下文的输入材料**；思考与工具循环另按 3–4× 余量预留

DSH 客户端：batch-executor 以 DSH preset 承接（install -BatchAgent 探测 ~/.dsh 自动装到
~/.dsh/.agent-presets/）。开会话时手动选模型「公司大模型(vLLM)/Qwen3.8-27B-W4A16-AWQ」
（preset 不约束模型，选错无纪律保护）；无链式派生，批末 commit 后手动开下一批说「执行下一批」。
