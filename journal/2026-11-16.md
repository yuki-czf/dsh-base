## 踩坑与修复（本日三个事故，均已闭环）

### 1. 退出后台残留（Antigravity 孤儿进程）

- 现象：关窗后残留 2 个无窗口 Antigravity.exe（各 ~110MB，Electron 退出竞态，非补丁引入）
- 修复双层：`退出反重力-清后台.bat`（手动兜底，taskkill 三件套+复检）+ `agy-watchdog.ps1`（自动）：启动器 bat 在 GOTIT/FALLBACK 两出口隐藏拉起，6s 轮询——有可见窗口=在用；连续 4 轮（~24s）无窗口但有残留 → 宽限 4s 复查防误杀 → 清三件套 → 自退；全干净退出也自退。多开多 watchdog 无害
- bat 编码两坑：rem 中文注释在 chcp 65001 生效前被 cmd 误解析（注释只写 ASCII）；timeout /t 无交互环境拒跑（换 ping -n 延时）

### 2. 登录失败：proxyconnect 127.0.0.1:7890 拒绝

- 现象：OAuth 换 token（POST oauth2.googleapis.com/token）报 7890 connectex 拒绝；浏览器登录成功
- 根因：早上按当时监听把启动器 PROXY 锁死 7890，下午 Clash Verge 混合端口漂回 7897 → 7890 成死端口 → 客户端带死代理环境变量换 token 必炸；浏览器走系统代理（7897/TUN）所以成功
- 修复：检测块升级三级级联 7897 → 7890 → NOPROXY（TUN 直连），goto 风格避开括号块解析坑。教训：这台机 Clash 混合端口会漂移，禁止写死单端口

### 3. 搜索岔路：MiniBar 同名混淆

## minibar 两个已知局限（源码级确认）

2. **字段无开关**：七项指标硬编码在 inject.js，无配置项；裁剪需加 HIDE 集合（本地补丁，更新会冲突）
3. 替代参照：antigravity-usage-monitor（yuhuan-dev）四配额池分离 + 原生字段开关，可整体替代 capsule；官方 Marketplace 是另一赛道（Skills/MCP/Agents/Rules/Hooks 五类），无监控类 sidecar

# 增补二（傍晚）：fast-io Windows 冲突实测 → PowerShell 版改写 → 复测通过

## 实测一：原版规则在 Windows 上失效一半

会话库取证方法（可复用）：`~/.gemini/antigravity/conversations/<uuid>.db` 是 SQLite（表 steps / gen_metadata / executor_metadata，protobuf 载荷）。原文件被 Antigravity 独占锁，须先以共享模式（FileShare.ReadWrite）复制再用 py sqlite3 解析；gen_metadata 500KB+ 的记录是含 `<user_rules>` 全文的完整请求快照，小存根（1.2KB）只有元数据。

对真实任务（esp2b media-tags 修复，gemini-4-hydrogen）的取证结论：

- ✅ 规则确实注入：`<RULE[...fast-io\rules\AGENTS.md]>` 位于系统指令区，声明优先级高于其他指令
- ✅ 整块读生效：17 次带行范围读取，中位 80 行，6 次 ≥150 行（最大 6459 行整读）；29 轮工具调用 26 轮并发
- ❌ 命令写法失效：Hydrogen 阶段 38 条命令 33 条含 `;`（87%）——原版规则明令禁止 `;`，但 PowerShell 链式语句（`Set-Location 'x'; $env:P='y'; python …`）必须用它；GNU `grep -rn` 12 次
- 模型遵守度差异明显：Argon 阶段 10 次读取 5 次整块读，Hydrogen 阶段 7 次仅 1 次——便宜模型对规则的遵守更松

## PowerShell 版改写

根因是规则写的是 Unix 世界观（禁 `;`、用 bash 白名单），与 Windows/PowerShell 环境冲突。改动：

- 上游原文备份 `rules/AGENTS.md.upstream`（4,684B）；新版 `AGENTS.md`（5,595B，UTF-8 无 BOM，65 行）
- 四点改写：① `;` 解禁（PS5.1 不支持 `&&`/`||`，`;` 是标准分隔符）② 检索工具换 `Select-String` / `Get-ChildItem` / `git grep`，禁 GNU 参数 ③ 减少审核的正解改为「多步写进临时 .ps1/.py 脚本一次跑」而非命令行堆语句 ④ 原版好条款全保留（150–300 行整读、同轮并行、edit_file 小改、回答砍短）
- 附带坑记录：.ps1 用 UTF-8 无 BOM；.bat 注释只用 ASCII（chcp 生效前中文被 cmd 误解析）
